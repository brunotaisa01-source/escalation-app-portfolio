# Portfolio context

This is a sanitized, local-first portfolio implementation of a generic escalation workflow application.

## What it demonstrates

- Frontend workbench and service/query contracts.
- ETL and deterministic local connector behaviour.
- Twelve automation definitions with preserved triggers, actions, branches, expressions, retries and handoff paths.
- Synthetic fixtures, flow package parity checks and end-to-end local tests.

## My contribution

I led the implementation and technical review across the application contract, frontend, local runtime adapter, automation definitions, fixtures, documentation and validation gates. This reflects the broader engineering scope I deliver alongside my official Data Analyst role.

## AI-assisted engineering

AI tools were used daily as an engineering accelerator for implementation, refactoring, documentation, test design, code review and repeatable QA. The resulting code and contracts were reviewed and validated locally.

The wider engineering workflow also uses an LLM harness, MCP integrations and retrieval-oriented context workflows where useful; these tools are not required to run this local demo.

## Data boundary

All records, identities, URLs, bindings and configuration values in this repository are synthetic or placeholders. No production tenant, credentials or operational data is included.
